Simulation, not a hiring predictionSimulated

Simulated review, not a hiring prediction. Eight simulated reviewers read the portfolio in three rounds, like a table read before the real thing. Real hiring depends on people, timing and roles that no portfolio read can model.

This is a practice run built from published hiring guidance, not expert advice. Made by iamdavidrivas, a product designer, not a hiring expert. Reviewers see only text and still images, so motion, prototypes and embedded players are never seen.

Rubric informed by Faire's design hiring post, Figma's recruiter tips and Nielsen Norman Group's portfolio survey.
